# Law-Advisor
The fine-tuned Law Advisor with LLaMA 3.2 (3B) is a specialized AI model designed to assist with legal queries and provide insights based on legal datasets. It leverages the LLaMA 3.2 3-billion parameter model, fine-tuned with LoRA (Low-Rank Adaptation) on curated legal datasets, including IndicLegalQA and Indian law resources.
